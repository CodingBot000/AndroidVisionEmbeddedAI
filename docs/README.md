# ROBOT VISION 포트폴리오 문서

Kotlin·Compose·MVI·Hilt 기반 Android 앱에 카메라 객체 탐지와 한국어 오프라인 STT를 통합한 프로젝트의 기술 문서 모음이다.

2026-10-25에 이력서·포트폴리오 독자를 기준으로 문서를 분류했다. 이후 사용자 확정에 따라 Git 제외 범위를 `docs/_private/`로 한정했다. 이 목차의 기술 문서와 화면 자료는 커밋 대상이며, 초기 작업 지시서·원본 로그·개인 시연 원고는 내부 보관한다. 제외 규칙 변경 자체가 커밋·푸시를 실행하는 것은 아니다.

## 구현과 검증의 경계

- 실제 Vision 경로는 EfficientDet-Lite0 + MediaPipe Tasks CPU이며, LiteRT 어댑터는 동적 출력 버퍼 계약을 실행 전에 검사한다.
- 한국어 STT는 sherpa-onnx + Moonshine v2를 사용한다. 녹음 후 처리하는 non-streaming 방식이다.
- [검증 요약](TEST_EVIDENCE.md)은 2026-10-17의 보관된 기록에 근거한다. 문서 분류 작업을 새로운 실기기 검증 결과로 취급하지 않는다.
- 실제 카메라·마이크·박스 정렬·명령 인식률·폰 성능·GPU/NPU·발열·장시간 안정성은 미검증이다.
- Simulation 이미지와 고정 confidence는 UI 동작 설명용이며 실제 물체 인식 결과나 정확도 수치가 아니다.

개발 작업 지시서·개인 시연 원고·원본 실행 로그는 이 공개 후보 문서 모음에서 분리해 로컬 보관한다. 의미 있는 장애 원인과 해결 방식, 미검증 사실은 기술 문서에 유지한다.
